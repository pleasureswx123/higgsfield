## 四、图片生成模型

模型：`mm-imagen2`

| 计费项目 | 价格 |
|---|---:|
| 输入 Token | `$5.00 / 1M` |
| 输出 Token | `$30.00 / 1M` |

实际图片请求链路按上游返回的输入 Token 和输出 Token 计费：

```text
图片费用 = 输入 Token × $5.00 / 1M + 输出 Token × $30.00 / 1M
```

代码中虽然定义了 `get_image_cost()` 和 `$0.0035 / 张` 的价格常量，但当前图片请求链路没有调用该函数，因此 `$0.0035 / 张` 不属于当前实际生效的扣费规则。

## 五、SD 视频模型

**当前生效计费单位：USD / 1M output tokens**  
**换算汇率：1 USD = 6.69 CNY**

SD 视频按任务完成后返回的 `completion_tokens` 计费，并根据模型版本、分辨率和是否包含视频输入匹配价格。表中的人民币价格为计费基准，系统在结算时换算为美元。

| 模型版本 | 分辨率 | 包含视频输入（CNY） | 包含视频输入（USD） | 不包含视频输入（CNY） | 不包含视频输入（USD） |
|---|---|---:|---:|---:|---:|
| SD 2.5 | 480p/720p | `¥42` | `$6.2780` | `¥70` | `$10.4634` |
| SD 2.5 | 1080p | `¥46` | `$6.8759` | `¥77` | `$11.5097` |
| SD 2.5 Fast | 480p/720p | `¥38` | `$5.6801` | `¥64` | `$9.5665` |
| SD 2.5 Fast | 1080p | `¥42` | `$6.2780` | `¥71` | `$10.6129` |
| SD 2.0 | 480p/720p | `¥28` | `$4.1854` | `¥46` | `$6.8759` |
| SD 2.0 | 1080p | `¥31` | `$4.6338` | `¥51` | `$7.6233` |
| SD 2.0 | 4K | `¥16` | `$2.3916` | `¥26` | `$3.8864` |
| SD 2.0 Fast | 480p/720p | `¥22` | `$3.2885` | `¥37` | `$5.5306` |

### 模型对应关系

| 模型版本 | 对外模型名 |
|---|---|
| SD 2.5 | `mm-nova-sd-2.5`、`mm-eva-sd-2.5` |
| SD 2.5 Fast | `mm-nova-sd-2.5-fast`、`mm-eva-sd-2.5-fast` |
| SD 2.0 | `mm-nova-sd-2.0`、`mm-eva-sd-2.0` |
| SD 2.0 Fast | `mm-nova-sd-2.0-fast`、`mm-eva-sd-2.0-fast` |

`nova` 和 `eva` 使用相同价格。请求内容中存在 `video_url` 时按“包含视频输入”计价；没有 `video_url` 时按“不包含视频输入”计价。

费用计算：

```text
USD/Token 单价 = 人民币百万 Token 单价 ÷ 6.69 ÷ 1,000,000
SD 费用（USD） = completion_tokens × USD/Token 单价
```

例如，SD 2.5、720p、包含视频输入，任务返回 `1,000,000 completion_tokens`：

```text
费用 = 1,000,000 × (¥42 ÷ 6.69 ÷ 1,000,000)
     = $6.278027
```

新任务会保留请求分辨率和视频输入标记。旧任务没有该标记时，兼容按 720p、不包含视频输入计费。

## 六、H3 视频模型

模型：`mm-h3`

| 计费项目 | 价格 |
|---|---:|
| 输出视频 | `$0.13 / 秒` |
| 参考视频 | `$0.13 / 秒` |
| 输入图片 | 前 5 张免费 |
| 超出 5 张的输入图片 | `$0.04 / 张` |
| 参考音频 | 免费 |

费用计算：

```text
H3 总费用 =
total_seconds × $0.13
+ max(image_count - 5, 0) × $0.04
```
