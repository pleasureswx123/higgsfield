# 内网部署与 NAS 存储方案

更新：2026-11-03；正式部署待确认，不是已上线说明。

## 目标

公司内网服务器运行管理端、制作端、共享API与后台工作器；PostgreSQL保存元数据和账本，Redis承载框架会话/缓存；媒体长期保存公司NAS。浏览器通过平台授权读写，供应商通过后台受控接口交互。

## 当前与正式环境区别

本地测试使用HF_STORAGE_ROOT和local-test模式；正式环境需要正确挂载NAS并配置StorageService。页面没有已实现的通用NAS路径设置向导；挂载、服务账户和网络由部署维护人员完成，可由平台管理员协调，不需要新增业务角色。

## 上线确认清单

- 操作系统、部署方式、服务器数量、反向代理和HTTPS。
- NAS协议、挂载路径、服务账户读写权限、容量、断挂检测和恢复。
- PostgreSQL与媒体一致性备份、恢复演练，账本及审计留存。
- 密钥配置、受控出网、日志脱敏、临时URL过期处置。
- 工作器托管与重启、积压/心跳/归档失败/待计价监控。
- 数据库迁移、应用版本与回滚方案。

禁止NAS不可用时无提示地写到另一块本地目录；不能把供应商临时URL当长期文件。不得从本地Docker方式推断正式容器化方案。
