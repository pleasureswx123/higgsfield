# 数据库详细设计 · 当前代码索引

更新：2026-11-03。以下表清单由当前 SQLAlchemy DO 声明提取；数据库实际结构必须以已执行 Alembic 迁移为准。它不宣称本次检查了生产数据库。

## 设计约束

PostgreSQL；bigint 自增主键；无物理外键；中文字段和表注释；公共审计字段；业务逻辑删除；账本和审计不可覆盖删除。关联完整性由 Service 事务、锁及联合唯一约束维护。不得用 create_all 或版本号修改替代迁移。

项目/文件夹是逻辑组织；stored_file保存物理存储信息；asset及version保存素材与版本；element_revision_media组织可复用参考；creation_job保存输入和价格快照；generated_output与素材关联；usage和billing分开保存事实及计算。

预算表存在不代表当前生成使用预算；项目专用路由表存在不代表管理员必须逐项目配置。当前生成使用实际用量计价和全平台默认模型。
