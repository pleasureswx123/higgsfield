## 实现

1. 人物素材先全部发起注册，再查询处理状态；仅明确的素材处理中等待改为5秒，异常与未知状态仍保留原重试间隔。已有上传与有效注册继续复用。
2. 对支持精确范围及强ETag的视频启用最多4连接下载；使用If-Range防止文件版本混合，严格核对范围、长度和类型，并校验文件摘要。普通下载保留回退路径。
3. 连接中断续传当前分段，每段最多3次请求；总时限、字节上限、HTTPS验证、域名和公网地址限制保持有效。没有新增付费生成重试。
4. 详情展示已下载/总量及校验阶段；进度约5秒上报，保留关键执行节点，关闭或刷新详情不会重新生成。

分段策略依据[HTTP Range与If-Range规范](https://www.rfc-editor.org/rfc/rfc9110.html#name-if-range)。目前未实现进程重启后的持久化断点；重启、总超时或分段耗尽重试仍会清理临时文件并进入原归档恢复流程。
