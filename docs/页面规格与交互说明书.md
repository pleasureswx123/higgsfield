# 页面规格与交互说明书

更新：2026-11-03。业务范围见[完整PRD](AI图片与视频制作平台PRD-全流程版.md)。

| 页面 | 主操作 | 交互约束 |
|---|---|---|
| 工作台 | 当前角色职责入口 | 费用角色不引导接入模型；用户/部门入口按权限显示 |
| 供应商与模型 | 供应商设置、新增模型、配置、测试记录、启停 | 连接与凭据复用；不让新管理员填写内部ID |
| 模型配置 | 确认能力价格，再测试启用 | 无逐项目开放步骤；已启用改价无需再测试 |
| 测试抽屉 | 先看Request，暂不测试或开始测试 | 打开不调用；提交显示loading；Response自动更新 |
| 用量与费用 | 条件查询、汇总、明细 | 明细抽屉；未计价明确；两种口径不可相加 |
| 项目素材 | 上传、预览、目录操作 | 保持原比例；元数据和次要操作按需展开 |
| 创作栏 | 图片/视频、模型、参数、参考、生成 | 默认模型来自可用目录；图片1:1；防重复；不堆财务内容 |
| 元素 | 选素材、命名、描述、引用 | 具体参考版本可辨；目前先上传素材再建元素 |
| 项目设置 | 成员和角色权限 | Owner特殊权限独立；高角色继承低角色 |

亮暗主题共用布局和语义色；主题切换保留输入。结论优先、技术细节按需展开。重复主题按钮与重复“查看测试内容”入口不应占据主操作区。复杂任务清楚显示正在执行、失败原因、结果及下一步，不能无限静态等待或要求普通管理员执行命令。
