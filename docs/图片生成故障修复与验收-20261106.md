## 修复内容

1. **供应商专属网络出口**：用精确域名选择本机出口；未配置域名保持默认行为。保持 TLS 校验、禁用自动重试与重定向。出口不可用时报错，不暗中切换出口重发。
2. **未知任务的有期限占用**：暂停自动核查的未知任务、结束但结果未知的管理测试，保护期后自动回收本地调度名额并追加审计。仍在执行或自动核查的任务不回收。未知任务、供应商响应和费用事实不变，不自动重发。已回收的未知任务不再永久占住受理队列上限。
3. **状态反馈**：区分正常排队与未知任务占用。任务受理后恢复创作入口，执行状态在状态卡显示；相同参数再次生成有费用提示。
4. **诊断**：记录请求字节数/摘要、阶段耗时、实际远端 IP、配置的本机出口、超时参数、系统错误链和安全响应头。请求写入客户端套接字不等于供应商已收到完整正文，不以 `requestSentAt` 单独证明供应商受理。
5. **API 退出保护**：SSE 长连接可能阻止开发热重载退出，设置 15 秒优雅停机期限，避免无限等待连接；独立工作器不随 API 退出。现场 API 不响应经重启恢复，未对旧进程采集堆栈，因此不声称已证明旧进程卡住的唯一原因。

## 本机与部署配置

本机后端 `.env.dev` 已配置如下（没有密钥）：

```dotenv
HF_PROVIDER_LOCAL_BINDINGS='{"llm-gw.videoplus.cc":"192.168.1.23"}'
```

这是**本机网卡地址**，不是供应商 IP。换电脑、DHCP 地址变化或正式部署时必须核对实际出口；不能把此地址照搬到服务器。生产环境应由运维固定出站网络；不需要让每位制作用户关闭自己的 VPN。未设置时默认 `{}`。
