# 媒体生成手动验收案例

执行顺序：图片 I1 → I2 → I3 → I4 → I5 → 视频 V1 → V2 → V3 → V4。图片基础链路通过后再进入视频；所有生成由测试者手动点击。

## 开始前与每例共同检查

- 使用专门的测试项目/文件夹，如“生成验收/图片”“生成验收/视频”。优先选择已启用且明确支持本例输入的模型；没有多图或视频参考能力时，记录“当前模型不支持”，不要强行提交。
- 每例先生成一份，固定模型和其他参数；图片使用页面默认分辨率，视频使用支持的最短时长。先不要同时更换多个参数。
- 先检查异常任务。结果未知的历史任务可能仍占共享凭据名额；必须核实供应商停止或未运行后才能释放，不能为测试畅通而直接改成失败。
- “人物/产品与参考图是否一致”属于生成质量；“引用有没有送错、丢失、串到另一任务”属于平台问题，两者分别记录。

| 阶段 | 手动检查 |
| --- | --- |
| 输入 | 能否找到模型、比例、引用入口；上传/选择中是否有反馈；移除引用是否直观；切换主题是否保留未提交输入 |
| 提交 | 点击后立即有明确反馈；准备/发送期间连续点击不新增重复任务；受理后能找到这次任务 |
| 等待 | 能区分排队、生成、保存、异常；看不出进度时不应显示虚假的完成百分比；关闭详情不会取消任务 |
| 再次进入 | 任务受理后刷新页面或切换文件夹再回来，原任务仍在，不能因查看/刷新再次生成 |
| 结果 | 预览与本次提示词、参考图相符；输出进入目标项目/文件夹；不能把供应商生成完成误当成归档完成 |
| 归档 | 保存完成后可以重新打开、下载；图片能正常查看，视频可播放/拖动/下载；刷新不重复建素材 |
| 异常 | 清楚说明发生在哪一步及下一步；结果未知不应诱导重新生成；归档失败的重试不重新调用生成 |

每例记录：点击时间、任务出现时间、开始执行时间、发现结果时间、归档完成时间。页面或记录缺少某个时间时写“未展示/未记录”，不要推算为供应商内部生成耗时。

## 图片 I1：纯文生图——机器人与幼苗

**代表意义：** 希望与科技共生。明确的轮廓、配色和道具为后续参考图一致性提供基准。

**操作：** 不添加任何参考图，比例选 1:1。

```text
商业产品摄影，一台小型奶油白色园艺机器人，圆角方形身体，头部只有一整块深蓝色玻璃面罩，胸前一枚橙色圆形徽章，没有文字。机器人双手捧着一个透明玻璃花盆，花盆内只有一株两片绿色叶子的幼苗。全身完整可见，正面偏转约十五度，站在浅灰色圆台上，纯净的浅灰背景，柔和的左侧自然光，真实的陶瓷、金属与玻璃材质，轮廓清晰，构图简洁，温暖而克制。画面只有一台机器人、一个花盆和一株幼苗，无水印、无额外文字。
```

**重点：** 完整跑通无引用生成到归档；保存结果作为 I3、I4、I5、V3 的参考。特别观察数量、徽章、面罩与玻璃材质。

## 图片 I2：纯文生图——黎明灯塔

**代表意义：** 指引与方向。检验宽画幅、空间布局、光线与天气，也准备后续场景素材。

**操作：** 清空上一例引用，比例改为 16:9。

```text
电影感写实海岸风景，黎明时分，一座红白相间的灯塔位于画面右侧三分之一处的岩石海岬上。一条湿润的石板小路从左下角通往灯塔，左侧保留开阔海面，远方地平线清晰。风暴刚刚过去，深蓝色云层出现一道暖金色晨光，灯塔发出柔和的光，海面有细小浪纹和淡淡薄雾。近景石板、中景灯塔、远景海天层次分明，真实自然的材质，安静、坚定、充满希望，无人物、无文字、无水印。
```

**重点：** 比例切换是否生效、实际结果尺寸是否正确、I1 与 I2 是否独立展示。保存结果供 I4、V2 使用。

## 图片 I3：文字＋单图——只改变环境

**代表意义：** 同一主体在不同情境中延续；检验“保留什么、改变什么”。

**操作：** 从 I1 结果选择“用于图片创作”，确认创作栏出现参考缩略图且没有自动提交。使用该参考，比例 16:9。

```text
以参考图中的园艺机器人为唯一主体，保持它的奶油白色圆角方形身体、深蓝色玻璃面罩、胸前橙色圆形徽章、身体比例，以及双手捧着的透明玻璃花盆和两片叶子的幼苗。把背景改为清晨的现代玻璃温室，机器人站在温室中的木质工作台上，周围有少量整齐摆放的绿色植物，阳光从左上方透过玻璃照进来。全身完整可见，真实产品摄影，主体清晰，背景轻微虚化。不要增加机器人，不要更换主体配色，不添加文字或水印。
```

**重点：** 素材动作只添加引用；提示词和引用均可编辑；生成后原图保持不变，得到独立新结果。

## 图片 I4：文字＋两图——主体与场景组合

**代表意义：** 希望抵达远方；检验多个参考的分工和组合。

**操作：** 添加 I1 与 I2，两张都能在创作栏辨认，比例 16:9。实际参考顺序改变时仍用内容描述区分，避免只写“第一张”。

```text
将机器人参考图中的奶油白色园艺机器人，放入灯塔参考图中的黎明海岬场景。机器人位于画面左侧前景的石板小路上，双手稳稳捧着透明玻璃花盆和两片叶子的幼苗，面向右侧远处的红白灯塔。严格保留机器人的深蓝色面罩、橙色圆形徽章与身体比例，保留灯塔的外形和海岸布局。机器人受到与场景一致的暖金色侧光，脚底与湿润石板自然接触，阴影方向一致，主体大小符合透视关系。电影感写实画面，只有一个机器人和一座灯塔，不要拼贴边框，不添加文字或水印。
```

**重点：** 两份参考没有丢失或重复；项目素材选择、上传入口的反馈明确。参考未成功附加时不应表现为可直接生成。

## 图片 I5：元素引用——同一角色持续制作

**代表意义：** 连续项目中的角色身份；检验元素选择及固定素材版本引用。

**操作：** 使用 I1 创建元素“园丁小白”。在输入框键入 `@`，从候选中选择该元素及具体参考；不要仅粘贴普通的 `@园丁小白` 文字。工具栏 `@` 入口也检查一次，移除重复选择后只提交一份。

```text
让已选择的“园丁小白”元素中的机器人出现在一间简洁的木工工作室。保持参考中的奶油白色身体、深蓝色面罩、橙色圆形徽章和整体造型。机器人站在木质工作台前，双手把原来的透明玻璃花盆轻轻放到桌面中央，花盆中仍是同一株两片绿色叶子的幼苗。窗外是明亮的春日庭院，室内暖色木纹与自然光相互呼应。中景构图，完整呈现机器人与花盆，真实电影剧照质感，无文字、无水印。
```

**重点：** 两个 `@` 入口的选择体验一致；候选属于当前项目；已选引用可辨认和移除。需要跨项目隔离检查时，使用另一个无授权账号查看，而不是假定项目素材对所有人私有。

## 图片 I6（可选）：中文海报——文字准确性

**操作：** 无参考，3:4（模型支持时），否则使用当前支持比例。此例用于生成质量对照，不把文字生成不准直接判定为平台 Bug。

```text
设计一张简洁高级的中文公益海报。米白色纸张背景，画面下方是一双机械手托着一小块泥土，泥土上长出一株鲜绿幼苗，侧面柔和阳光，细腻纸张与金属材质。画面上方只出现两行清晰中文：第一行“向光而生”，第二行“让科技守护每一份生机”。主标题大，副标题小，字距舒展，排版居中，黑色文字，不要出现其他文字、标识、乱码或水印。主题表达科技与自然共同成长。
```

## 视频 V1：纯文生视频——灯塔扫光

**代表意义：** 从静态场景到时间变化；检验无参考的视频提交、查询、归档和播放。

**操作：** 不添加参考，16:9，选择模型支持的最短时长。

```text
一个连续的电影感写实镜头。黎明的海岬上，一座红白相间的灯塔矗立在画面右侧，深蓝色海面有缓慢起伏的小浪，薄雾轻轻向左移动。灯塔的暖色光束缓慢扫过海面，地平线逐渐透出金色晨光。摄影机保持稳定，只做非常缓慢的向前推进。保持灯塔结构和海岸轮廓稳定，不切换镜头，不出现人物、文字或水印。
```

**重点：** 供应商受理后仍应继续显示生成/保存状态；播放的是实际归档结果；查询、刷新、重新打开详情不新增生成任务。

## 视频 V2：文字＋场景图——让静态图片动起来

**代表意义：** 保留场景、加入克制运动；检验图片进入视频创作的路径。

**操作：** 在 I2 上选择“用于视频创作”，检查只加入参考，没有自动生成。16:9，最短时长。

```text
以参考图片作为场景和构图依据，保留红白灯塔的位置、石板小路的走向、海岸轮廓和黎明配色。让海面的细小波浪缓慢推进，薄雾轻柔漂移，灯塔光束缓慢扫过远处海面。摄影机从参考图对应的视角开始，非常缓慢地向前推进，整段保持连续稳定。灯塔和石板小路不变形，不新增建筑、人物或物体，不切镜，无文字、无水印。
```

**重点：** 参考图选择、比例与输入提示是否清楚。普通参考图不自动等同于严格首帧约束；没有首帧能力时不按“首帧像素一致”验收。

## 视频 V3：文字＋主体图——角色动作一致性

**代表意义：** 角色身份在运动中延续；检验主体、道具和细小动作稳定性。

**操作：** 使用 I1；如模型支持 1:1，沿用参考比例，否则明确选择支持的比例。最短时长。

```text
以参考图中的园艺机器人为唯一主体，保持奶油白色身体、深蓝色玻璃面罩、橙色圆形徽章及身体比例不变。机器人双手始终稳稳捧着透明玻璃花盆，花盆内保持一株两片叶子的幼苗。机器人缓慢地把头向幼苗方向低下一点，然后轻轻抬回，幼苗叶片被微风吹动，动作细微自然。固定摄影机，柔和光线，保持原有简洁背景，单一连续镜头。不要增加手臂、手指、机器人或花盆，不改变物体数量，无文字、无水印。
```

**重点：** 区分角色变形等模型质量问题与参考发送错误；视频实际比例、时长应与所选参数及模型约束一致。

## 视频 V4：文字＋多图——主体进入场景

**代表意义：** 团队素材组合成连续镜头；检验多参考视频路径。

**操作：** 仅在当前模型明确支持多图参考时使用 I1＋I2；否则记录能力限制并跳过。16:9，最短时长。

```text
使用机器人图片确定角色造型，使用灯塔图片确定环境与光线。一个连续的写实电影镜头：奶油白色园艺机器人站在黎明海岬的石板小路左侧前景，双手捧着透明花盆和两片叶子的幼苗，缓慢向远处的红白灯塔迈出一步，然后站稳。机器人造型、徽章、面罩和花盆始终保持一致，灯塔与海岸轮廓稳定。海浪轻缓起伏，金色晨光照亮主体，摄影机保持固定。动作克制，不切镜，不新增角色，不出现文字或水印。
```

## 视频 V5（可选）：文字＋视频参考——运动参考复用

**操作：** 仅在模型明确支持视频参考且 V2 已归档时，选择 V2 作为视频参考。若页面没有对应能力入口，不以其他输入类型替代提交。

```text
参考输入视频中缓慢向前推进的摄影机运动和海浪节奏，重新创作一个连续的海岸灯塔镜头。保留灯塔、石板小路和海岬的空间关系，把时间改为日落后的蓝调时刻，天空呈深蓝与淡紫渐变，灯塔发出温暖的金色光束，薄雾轻柔漂移。运动速度平稳，建筑结构不变形，不增加人物，不切镜，无文字、无水印。
```

**重点：** 视频参考可选择、可移除且有清楚反馈；上传/处理等待可理解；新输出不能覆盖原视频。

## 多人制作补充检查

基础图片通过后，再用两个不同制作人账号同时提交各一个 I1 或 I2；视频基础通过后同样各提交一个 V1。使用不同浏览器配置或无痕会话，避免共享登录态。

- 共享名额为 1 时，一人执行、另一人排队是正确行为；重点是排队反馈明确且前项结束后后项继续。
- 任务的发起人、参数、参考、项目和目标文件夹不能串线；同项目能否看到他人作品按配置的项目权限判断。
- 一个制作人关闭详情、刷新页面，不应影响另一人的任务。
- 真实付费测试不要为了验证上限而连续提交几十个任务；高并发上限已使用隔离数据库模拟验证。
