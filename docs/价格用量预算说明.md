# 价格、真实用量与费用结算说明

更新：2026-11-03。保留旧文件名以兼容链接；**当前不配置预算、不做资金预占**。

## 配置与记账

平台管理员在模型配置页维护价格与汇率。费用管理员查询、统计、核对供应商账单，并按独立授权处理差异。项目价与采购价首版同价，以 USD 分别记账；不能相加为总费用。管理员测试归入非项目消耗。

模型已启用后修改价格产生新版本，不重新付费测试；已提交任务使用固定的价格和汇率。历史原始金额保留，差异采用追加调整。缺少用量或价格时显示待核算，不能填零或用估价当实际费用。

## 计算规则

图片：输入 Token × 5 / 1,000,000 ＋ 输出 Token × 30 / 1,000,000 USD（初始单价，可配置）；0.0035 USD/张不是当前生效规则。

SD：最终 completion_tokens × CNY 百万 Token 单价 ÷ 固定汇率 ÷ 1,000,000。初始汇率 6.69；按模型版本、分辨率和实际 video_url 输入选择档位；图片参考不算视频输入。nova/eva 对应版本同价。

## 证据与对账

SD 最终 Token 来自查询视频任务成功响应，不来自创建任务的初始零 usage。图片读取内层 content 的 usage。保留发起人、部门快照、项目或成本中心、任务和供应商标识、参数、用量、价格/汇率版本、原始金额与调整证据。

对账模块提供导入、匹配和差异处理代码；真实账单格式、角色范围与人工闭环需验收。平台费用记录不是自动取得的供应商正式账单。
