# 测试与验收方案

更新：2026-11-03。详细场景见[人工验收操作手册](人工验收操作手册.md)；业务通过标准为[PRD](AI图片与视频制作平台PRD-全流程版.md)的PRD-01～12。

| 层级 | 测试重点 | 不能替代的验证 |
|---|---|---|
| 单元/契约 | 参数、价格精度、响应解析、权限继承、幂等和状态转换 | 真实供应商协议行为 |
| 数据库集成 | 事务、唯一关联、真实迁移、并发受理与重复归档 | 正式NAS及浏览器操作 |
| 前端组件 | 草稿恢复、默认参数、提交锁、轮询刷新、抽屉 | 登录后完整业务流程 |
| 手工业务 | 接入、图片、视频、人物参考、元素、费用、角色 | 生产恢复演练 |
| 部署验收 | 挂载、备份恢复、进程托管、网络、密钥和权限 | 不能仅以服务存活判断业务通过 |

回归重点：不可重复付费；价格更新不影响运行中任务；视频Token取最终轮询；归档失败不重生成；原目录失效不丢输出；未计价可见；高角色覆盖低角色权限且不越系统授权。

本次文档同步只进行Markdown/链接/代码路径检查，不新增业务测试结果，不发起付费测试。
