# 项目与系统权限矩阵

更新：2026-11-03。当前口径见[完整 PRD](AI图片与视频制作平台PRD-全流程版.md)第 2～3 节；实现见[技术方案](技术架构方案.md)第 12 节。

## 系统权限与项目权限

系统角色控制平台功能资格，项目角色控制具体项目内容。平台管理员管理供应商与模型；费用管理员查看、统计和对账；制作平台使用者按项目成员身份参与制作。综合管理员是平台、费用、用户及部门权限的组合；超级管理员负责框架系统管理。

拥有某个模型的使用资格不等于能够访问所有项目。用户/部门管理按实际权限显示，不以管理员名称猜测权限。

## 项目权限层级

Owner ≥ 负责人（admin）≥ 制作人（producer）≥ 查看者（viewer）；范围为全项目 ≥ 本人 ≥ 无。高角色继承低角色有效权限。Owner 唯一且固定项目业务权限；非 Owner 受系统授权上限约束。

| 动作 | Owner | 负责人 | 制作人 | 查看者 |
|---|---|---|---|---|
| 查看项目、素材、元素、生成记录及评论 | 是 | 是 | 是 | 是 |
| 下载素材 | 是 | 是 | 是 | 是 |
| 上传、生成、引用、创建元素 | 是 | 是 | 是 | 默认否 |
| 管理目录 | 是 | 是 | 是 | 默认否 |
| 编辑、删除和审核内容 | 全项目 | 全项目 | 部分能力限本人 | 默认否 |
| 管理制作人、查看者 | 是 | 是 | 否 | 否 |
| 管理负责人、转让所有权、配置角色矩阵 | 是 | 否 | 否 | 否 |
| 跨项目复制 | 源目标均需满足条件 | 按项目配置 | 按项目配置 | 按项目配置 |

本表为默认职责摘要，具体动作以权限目录和项目配置为准，不替代对象校验。上级不能通过设置无权限压低低角色已经获得的权限。

20261103_87 迁移补齐下载及层级一致性，移除误导性的生成取消权限；当前实际用量生成不支持提交后取消。权限变更与账号失效仍须检查前后端会话和实时授权，不以按钮隐藏代替后端拒绝。

验收：四角色分别访问同一项目；检查下载、上传、生成、本人/他人素材编辑、成员管理、Owner 转让；修改低角色能力后验证高角色继承；构造越权 API 请求应拒绝。测试不应额外调用付费模型来验证权限拒绝。
