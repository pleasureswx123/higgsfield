# mm-imagen2 配置与手动测试

日期：2026-11-02。本文对应本轮代码；真实供应商调用、浏览器完整流程和公司 NAS 由用户手动验收，尚未宣称通过。

## 从空白状态手动接入（当前推荐步骤）

本轮已按用户要求清理 2026-11-02 由 hf_test_platform 创建的供应商、模型与关联测试、调用、用量、价格、审计记录。项目、素材、用户、角色和系统测试成本中心保留；数据库自增编号不重置。

1. 用 `hf_test_platform` 登录，按 Ctrl+F5 刷新管理端，打开“供应商与模型”，应看到“先连接你的供应商”和空模型列表。
2. 点击“配置供应商”。供应商名称使用 `VideoPlus MM`，API 地址使用 `http://llm-gw.videoplus.cc/`，粘贴供应商 API Key（不含 Bearer）。其他项保留默认即可：采购账号 `videoplus-mm-main`、业务标识 `op`、区域 `default`。不要填写任何内部 ID。
3. 点击“保存供应商与密钥”。此操作仅保存配置，不调用供应商。成功后点击“下一步：添加模型”，应自动打开新增模型窗口。
4. 点击“选择 mm-imagen2 图片模型（已支持）”，名称、模型标识和图片类型自动填入。点击“保存模型”，应回到列表并看到 mm-imagen2。此时仍未产生供应商费用。
5. 点击该模型的“查看 / 继续配置”，应直接进入模型与价格确认，无需重填供应商密钥。能力版本不存在时显示预设说明，不要求管理员填写版本号。
6. 确认输入单价 `5`、输出单价 `30`，单位为 USD / 百万 Token；价格依据已有预填文字。点击“确认价格并继续”，自动保存能力及价格草稿。
7. 页面显示“测试服务已就绪”后，再点击“测试连接（生成 1 张）”。本次旧测试已删除，所以这是一次新的真实供应商调用，可能收费。等待页面自动更新，勿重复点击。
8. 测试通过后点击“启用到全平台”。看到成功提示后返回模型列表，应显示“已配置全平台使用”。不需要选择项目。
9. 制作端分别进入原有项目和新建项目，有创作权限的成员应能选择 mm-imagen2 并生成；其他成员权限保持原样。
10. 第二个模型直接点“新增模型”，复用同一供应商。未知模型显示待适配，不套用图片模型的接口和计费规则。

体验检查：空字段应在相应输入旁提示；供应商保存成功应明确提示下一步；刷新列表不重复创建或测试；主题切换不清空输入。真实浏览器交互和供应商生成仍由用户手动验收。

## 1. 本轮流程

平台管理员配置供应商、密钥、模型、价格、全平台默认配置和运行环境。费用管理员只查看消耗。

用户点击生成 → 后端校验 → 任务入库 → 图片工作器调用供应商 → 保存原图并加入提交目录 → 费用工作器分别记录采购、项目费用。

- 不配置预算、预占或报价签名；不弹费用确认框，不提供取消按钮。
- 输入和输出分别按 $5/$30 每百万 Token 计费，币种 USD。两套记录是同一次消费的两个口径，不能相加作为总费用。
- 图片参考由后端 Base64 直传，不自动缩放压缩。平台初始保护限制为 PNG/JPEG/WebP、单图 10 MiB、合计 32 MiB、最多 16 张；不是供应商承诺，可由管理员按核实结果调整环境变量。
- 超时或响应不完整时不自动重新生成；有完整响应证据时仅恢复解析和保存。
- 生成过程中目录被删除，不擅自改存其他目录；图片保留在生成记录，可从任务详情另存素材。

## 3. 平台管理员配置（按顺序）

### 第一步：供应商连接与账号

在后台“供应商管理”新增测试连接：

| 字段 | 值 |
|---|---|
| 名称 | VideoPlus MM |
| 基础地址 | `http://llm-gw.videoplus.cc/` |
| 适配器版本 | `videoplus-v1` |
| 允许域名 | `llm-gw.videoplus.cc` |
| 连接／读取／操作超时 | `15`／`180`／`240` 秒 |
| 任务超时 | `3600` 秒，属于任务整体生命周期，区别于单次操作和工作器时限 |

`X-Biz-Id: op`、Bearer 和 JSON 请求头由后端组装。不要将 `/v1/chat/completions` 再填进基础地址。

连接下面登记账号，填写能辨识实际采购账号的编码及上游项目标识。区域字段是平台匹配标识，可统一使用 `default`；后面的模型版本区域必须完全一致。如果供应商另有区域约束，使用其明确值。

### 第二步：模型及规格

在“模型管理”创建图片模型，选择刚才的连接，编码、显示名均可填 `mm-imagen2`。

1. 新增能力版本，点击新增的 **“填入 mm-imagen2 图片预设”**。
2. 确认网关别名 `mm-imagen2`、底层模型 `gpt-image-2`；区域与账号一致。
3. 保存草稿版本。预设保留比例、1K/2K/4K、质量、1～4 张、输出格式、压缩值。
4. 在该版本下登记一个精确规格，预设没有计价维度，表单中无需填写维度字段，直接保存（提交内容为 `{}`）。Token 单价不随尺寸区分，因此无需给每个尺寸重复登记规格。
5. 记录模型身份 ID、模型版本 ID、规格 ID，后续填写路由和价格时不要混用。

### 第三步：价格

在价格管理中：

1. 新增价格来源，类型选“人工确认”，摘录填写供应商提供的 Token 价格、确认日期和来源说明。不要填写 `$0.0035/张`。
2. 为上一步的规格创建 **采购价格簿**，币种 USD，关联实际供应商账号。
3. 新增价格版本，点击 **“填入 mm-imagen2 价格”**，填入来源 ID，保存草稿。此时模型尚未发布，不能提前发布价格。
4. 再创建 **平台价格簿**，币种 USD，不关联供应商账号，关联同一规格；按同样预设保存草稿。

两份价格均为：`input`、单位 token、基数 `1000000`、单价 `5`；`output`、单位 token、基数 `1000000`、单价 `30`。线性计费、起点 0、无上限、计算精度 10 位。

无需创建预算、预算周期、汇率或预占配置。

### 第四步：密钥测试与启用

1. 在“凭据管理”选择账号，创建凭据身份和密钥版本；关联当前连接配置版本，在密钥框录入 API Key，有效开始时间不能在未来。
2. 启动前述工作器。
3. 申请一次凭据测试，选择刚创建的图片模型版本、费用归属“管理员测试”。这一步会生成一张测试图，可能收费。
4. 刷新测试记录，等到完成且模型验证通过；使用成功记录启用密钥版本。
5. 本轮已修复：启用密钥时，会同时启用其已测试的当前连接配置。回供应商页面刷新，应看到连接已启用。
6. 回模型管理，登记该测试编号作为验证证据，再发布模型能力版本。
7. 模型发布成功后，再回价格管理发布采购、平台两份价格草稿，生效时间选择当前或过去的正确时间。接入助手会按此顺序自动执行。

如果测试超时或结果待确认，先核查该测试记录，不要反复申请测试。测试用量由原有凭据测试流程记录。

### 第五步：全平台配置与项目权限

在模型接入助手第三步点击“启用到全平台”，现有和新建项目自动可用，不再填写项目 ID 或逐项目添加路由。已有供应商与价格记录复用。

制作账号仍须具备该项目的生成、任务读取、素材读取与引用权限；需要上传则还需上传权限。项目负责人按现有项目权限体系操作。高级设置中的“项目专用配置”仅作可选覆盖用途，已有专用配置保留并优先尝试。

重新进入制作端项目，选择 `mm-imagen2`，应出现真实模型选项而非“待接入”。

平台管理员使用现有系统角色授予供应商、凭据、模型、路由及价格维护/发布权限；费用管理员仅授予费用读取菜单及 `billing:read`，不授予价格修改、预算管理和费用调整权限。采购费用查询按现有后端规则要求相应角色的数据范围为全部；首次配置可由现有系统管理员完成。

## 4. 你手动测试的顺序

每次先测 1 张，确认成功后再测下一项。

| 步骤 | 操作 | 应看到的结果 |
|---|---|---|
| 1 | 进入测试项目的一个文件夹，选择模型，输入“一只橘猫坐在窗台，柔和日光”，16:9、2K、High、1 张，点击生成一次 | 无费用确认框；出现任务编号/排队或生成中；没有预算配置也可受理 |
| 2 | 等待结果，打开任务详情 | 图片保存成功；当前目录自动出现生成图片，可预览和下载；请求映射尺寸为 2048×1152，实际文件宽高可在下载后查看 |
| 3 | 刷新页面 | 图片仍在原目录，最近任务状态可恢复；不会因刷新再次生成 |
| 4 | 选择 Auto | 分辨率显示“自动”且不可操作；切回 16:9 恢复原 2K。再分别查看 1K、4K 的尺寸提示 |
| 5 | 点“＋”上传一张小于 10 MiB 的 PNG/JPEG/WebP，选作参考，提示“保持主体，改为水彩风格”，生成 1 张 | 后台使用原图 Base64；无需公网图片地址；结果保存到提交目录 |
| 6 | 选择两张参考，描述“融合图片1和图片2的元素”，生成 1 张；再用“@”引用已有图片元素 | 两种入口都按固定图片版本及顺序发送；视频引用不能混入图片模型 |
| 7 | 设置数量 2，生成一次 | 一个任务、两张独立输出；实际用量是请求总量，不能再乘 2 |
| 8 | 提交后关闭页面，稍后重新进入项目 | 后台继续处理，图片保存在原提交目录；无取消入口 |
| 9 | 修改提示词、参数、引用，再切换亮暗主题 | 页面输入和选择保留；菜单可读；媒体原图不反色 |
| 10 | 费用管理员进入“费用记录”，按任务 ID 查询 | 平台、采购两条 USD 记录；查看输入和输出 Token。公式为 `(输入×5 + 输出×30)/1000000` |

若费用暂为待确认，先确认 billing 工作器在运行并刷新。用量缺失不会记为免费；图片保存不因费用待核实而被隐藏。

## 5. 常见问题定位

| 现象 | 先检查 |
|---|---|
| 模型仍显示待接入 | 模型版本是否发布、是否完成全平台启用、账号与模型区域是否一致 |
| 提示缺少价格 | 同一规格的采购与平台价格簿是否都是 USD、已发布且已生效，采购账号是否正确 |
| 任务持续排队 | image 工作器是否运行；任务详情是否有准备错误；凭据是否已启用 |
| 超时或结果待确认 | 查看原任务和供应商记录，不能为了测试恢复而重新点生成 |
| 生成返回但保存失败 | 存储可写性、磁盘空间、图片/解码容量；运行 image-recovery 或点任务详情“重试归档”，不会重新生成 |
| 图片有了但目录没看到 | 是否在提交时的原目录；是否目录被删除；刷新目录或在生成记录查看输出 |
| 费用一直待确认 | billing 工作器、内层真实用量、已固定的价格版本；不能用外层零 Token 补算 |

有问题时反馈：当前步骤、任务/测试编号、界面错误文本、相关脱敏工作器日志。不要发送 API Key 或完整 Base64。

- `POST /api/v1/generations/validate` 仅校验输入、授权、路由、价格，返回 `valid/issues/normalizedParameters/estimateVisibility`；不要求或签发估价凭据。
- `POST /api/v1/generations` 独立重新校验并以幂等键受理，不预占预算；固定两套实际价格版本。
- 任务列表增加 `folderId` 与 `rootFolder` 筛选；目录状态只查询后端任务，不重新提交供应商。

- 新任务不提供取消操作；旧预算账本保留，不删除历史数据。

## 全平台模型手动验收

1. 重启后端，刷新管理端；模型接入只显示三步，已有数据可直接选用。
2. 已有模型无需再次付费测试。完成前两步，第三步点击“启用到全平台”，看到成功提示。
3. 制作端打开一个原有项目，刷新后能选择 mm-imagen2；用有创作权限的账号生成一张，检查原目录归档与用量记录。
4. 新建项目，不配置任何项目专用路由，确认同样能选择模型并生成。
5. 非项目成员不能访问该项目；无创作权限成员不能发起生成，暂停或归档项目不能提交生成。
6. 管理端高级设置中的项目专用配置仍保留；平台工作台显示全平台模型数，不再提示逐项目开放。
7. 重复点击启用或重新进入助手应复用配置，不新增付费测试；亮暗主题均显示三步与完成提示。


## 测试透明度与服务状态

- 普通管理员无需执行 PowerShell。页面自动读取测试服务心跳；未就绪或运行代码版本不匹配时禁用新测试，后端同样拒绝受理，提示联系平台维护人员。
- 点击“查看请求 / 响应详情（不重新测试）”可查看脱敏请求、cURL、HTTP 状态、实际响应结构、图片预览、像素尺寸及 Token 用量。查看和复制不会调用供应商；自行执行 cURL 则会产生一次新的调用。
- 新测试在发送意图事务中留存请求快照。旧测试仅在重建请求的摘要与原请求摘要一致时展示，并明确标注来源；不能还原时不展示猜测参数。
- 响应来自本次已保存的加密证据，摘要验证及解密后有界解析。Base64 用长度摘要替代，未知字段不透传；图片预览仅为展示生成缩略图，不修改原响应图片。
- 2026-11-02 测试 2 的原响应为有效 1024×1024 PNG，输入 16 / 输出 7024 Token；旧工作器误判空尺寸与格式字段。已更新本地工作器、复核原响应并保留修复审计，没有重发请求。
