# 视频模型配置与手动测试

适用于当前本地开发环境。真实供应商生成由管理员手动点击，本文不要求管理员执行命令行。已有 mm-imagen2 和供应商密钥继续保留。

## 一、添加第一个视频模型

1. 打开管理端 `http://localhost:5173`，使用平台管理员 `hf_test_platform` 登录。如果提示登录过期，重新登录；页面未成功加载时显示空列表不代表配置已删除。
2. 进入 **平台管理 → 供应商与模型**。确认能看到已有 VideoPlus MM 和 mm-imagen2，不需要重新配置供应商。
3. 点击 **新增模型**，在“选择模型”中选择 **SD 2.5 标准版 · 国际站（mm-eva-sd-2.5）**。名称自动填写，点击 **保存模型**。不需要填写模型 ID、版本或价格簿。
4. 进入该模型的 **配置模型**。已有供应商连接、采购账号和密钥自动复用；在“确认模型与价格”核对分辨率与价格后，点击 **确认价格并继续**。该步骤只保存配置，不产生生成费用。
5. 选择“测试费用归属”（有一个选项时会自动选中）。确认页面显示“测试服务已就绪”。点击 **开始测试（生成 1 个视频）**：这是本流程第一次真实付费调用，会生成 720p、5 秒、16:9 的海边视频。
6. 等待测试完成。可以点击 **查看请求 / 响应详情（不重新测试）**，查看实际请求、脱敏 cURL、提交返回的任务 ID、查询地址、最终响应和用量。点击 **查看已保存的测试视频** 播放结果。刷新、查看、离开后回来不会重新提交生成。
7. 测试通过后点击 **启用到全平台**。价格随模型发布生效。回到模型列表，状态应为 **已配置全平台使用**。已有项目和新项目自动可用，不需要逐个勾选项目。

其他视频模型重复第 3～7 步；不用重复登记供应商或密钥。每个新模型的真实生成测试分别收费。已通过测试、已启用的模型会复用已有记录，不自动重测。

## 二、制作端生成与归档

1. 用制作平台账号打开 `http://localhost:5174`，进入有创作权限的项目和目标文件夹。查看者不能生成，原项目权限不变。
2. 在底部创作栏切换 **视频**，选择刚启用的 `mm-eva-sd-2.5`。
3. 首次使用建议选择 **16:9、720p、5 秒、标准码率、生成声音开启**，输入“海浪缓缓拍打沙滩，固定镜头，自然日光。”。每次生成一个视频。
4. 点击 **生成**，只点击一次。前台直接提交，后台执行；没有费用确认框、预算预占或取消按钮。
5. 到 **项目生成记录** 查看进度。刷新页面后应仍显示同一任务；等待“生成完成”以及视频归档完成，再播放或在素材列表查看。供应商完成与平台归档完成是两个状态，暂未归档不能冒充已保存。
6. 归档失败时只重试归档，不重新提交视频生成。结果不明的提交不会自动重发，避免重复费用。

## 三、参考图、虚拟人物与参考视频

- 普通图片：通过创作栏 **＋** 选择项目素材，使用“参考图”角色。
- 虚拟人物图片：先选好 SD 视频模型，再打开 **＋**，找到图片卡片的 **引用设置**，将“引用角色”选择为 **虚拟人物（自动注册素材）**，再加入引用。已有普通参考图若需要改为虚拟人物，可移除引用后按此步骤重新加入；不用删除原素材。
- 系统自动执行：上传图片 → 注册素材 → 查询素材状态 → Active 后以 `asset://素材ID` 作为 `image_url.url` 提交。国际站使用 eva 素材库，国内站使用 nova，互不混用。用户无需复制 URL 或素材 ID。
- 参考视频：添加视频素材并使用“参考视频”角色；系统据实际引用内容匹配“包含视频输入”价格，不能靠手动参数切换便宜档。
- 供应商素材仍处于 Processing 时，平台等待并继续查询，尚不会提交视频生成；注册失败或结果不明时展示对应诊断。

## 四、检查费用

1. 用费用管理员登录管理端，进入“用量与费用 → 费用明细”，按时间、模型或项目找到本次记录。管理员测试归属管理成本中心，制作任务归属项目。
2. SD 使用最终查询响应的 `usage.completion_tokens`。创建任务响应中的零 Token 不作为最终费用。
3. 计算方式：`实际输出 Token × 人民币百万 Token 基准价 ÷ 任务固定汇率 ÷ 1,000,000`。初始汇率为 6.69，例如 SD 2.5、720p、没有参考视频初始价为 70；有参考视频初始价为 42。参考图片和虚拟人物图片不算“视频输入”。管理员可在模型配置页修改价格和汇率，新提交任务使用新价格。
4. 制作任务的采购费用和平台费用分别记录 USD、价格相同。测试只产生对应采购消费，不应冒充项目生成费用。不要把两套账相加当成供应商扣款。
5. H3 使用 `total_seconds × 0.13 + max(image_count - 5, 0) × 0.04`；total_seconds 已含参考视频秒数，不再重复加一次。缺少真实计数时保留待核对状态，不伪造零费用。
6. 刷新记录、重复查询或重试归档后，原调用的费用不应新增一笔。

## 五、建议的手动验收顺序

| 顺序 | 操作 | 应看到的结果 |
|---|---|---|
| 1 | 查看原 mm-imagen2 配置 | 供应商、密钥、图片模型及价格仍存在 |
| 2 | 添加并保存 SD 2.5 | 自动填写能力、自动匹配价格，未自动收费 |
| 3 | 手动测试 SD 2.5 | 请求与查询可查看，完成后视频可播放、用量可查 |
| 4 | 启用模型 | 无需选择项目，制作端可选 |
| 5 | 纯文本生成 | 同一个任务完成、归档并显示费用 |
| 6 | 虚拟人物图片生成 | 自动上传、注册并使用素材 ID，无需手工传参 |
| 7 | 参考视频生成 | 匹配含视频输入价，生成结果可播放 |
| 8 | 等待时刷新页面 | 原任务继续，不重复调用生成接口 |
| 9 | 新建项目及查看者账号 | 新项目自动可选模型；查看者仍不能生成 |
| 10 | 切换亮/暗主题 | 选择和输入保持，表格、弹窗和按钮可读 |

每次点击真实测试或生成都可能收费，不要求一次验收所有模型；先走通一个 SD 模型，再逐个启用其他模型。

## 六、修改价格与汇率（不产生供应商调用）

1. 用平台管理员登录，进入“供应商与模型”，在目标模型行点击“配置模型”。
2. 在“确认模型与价格”页，SD 模型可直接填写“换算汇率（1 USD = 多少 CNY）”，以及每个分辨率的“含参考视频”“无参考视频”人民币百万输出 Token 单价。H3 按美元计价，直接修改视频秒价和超额图片单价，不需要汇率。
3. 已启用模型点击“保存价格并生效”。项目价和采购价在同一次事务中同步生效，页面显示保存成功；不会重新进行生成测试。尚未启用的模型显示“保存价格并继续”，先保存草稿，不会自动调用供应商。
4. 返回模型列表，再次进入“配置模型”，确认价格和汇率为刚保存的值；切换亮色/暗黑主题，未保存输入应保留。
5. 在“运行记录 → 调用记录”确认没有新增生成测试；在费用明细确认原有金额不变。如果已有进行中的任务，其完成结算仍使用提交时固定的价格版本。
6. 可将汇率填为 0 或价格填为负数，点击保存应提示修正且不写入。改回正确值即可继续。若临时修改价格用于验收，验收后在同一页恢复真实报价并保存。

保存会建立新的价格版本，不覆盖历史价格正文；供应商单价与汇率不会被提前换算成四位小数美元报价，结算仍采用高精度计算。

## 七、当前能力边界

- 目录包含 eva/nova 的 SD 2.0、2.0 Fast、2.5、2.5 Fast，以及 H3，共 9 个视频模型。
- SD 标准版提供 480p/720p/1080p；Fast 只提供 480p/720p。报价表与能力说明冲突的 Fast 1080p、SD 2.0 4K 暂不开放。
- SD 支持 4～15 秒和自动时长；H3 为 2K、4～15 秒。没有开放未经成功响应证实的 30 秒。
- H3 首尾帧与普通参考素材模式不能混用；H3 的虚拟人物素材 ID 接入尚无明确供应商契约，因此不提供该选项。
- 当前制作端提供图片、视频参考与输出声音开关。参考音频上传未开放：供应商临时上传接口只声明图片、视频，平台现有素材类型也不包含音频。不会将音频冒充图片或视频上传。
- 本地当前存储上限沿用已有配置；供应商允许的文件大小不等于平台必然允许的大小。正式环境需接入公司 NAS；本地归档成功不等于正式 NAS 部署已验收。
- 本次自动验证使用隔离数据库和本地回环 HTTP/HTTPS，没有真实供应商生成。供应商实际可用性、真实输出与最终对账由上述手动步骤验收。

## 八、在测试页查看 Request 与 Response

1. 进入模型的“测试并启用”步骤，选择测试费用归属。主页面只显示模型、状态与操作；如需提前核查参数，点击“查看测试内容”打开抽屉，未开始时明确显示请求尚未发送。
2. 展开“查看 / 复制 cURL”，密钥应为占位符。复制、展开和刷新都不生成视频；自行替换密钥执行 cURL 则会另行发起生成。
3. 由管理员手动点击一次“开始测试”后，自动打开详情抽屉并提交一次测试；Request 随后切换为实际发送快照，创建响应显示供应商任务 ID。关闭抽屉不取消后台任务；点击“查看测试详情”可再次打开，不重复生成。
4. 展开“查询视频任务”，查看查询地址、最近一次已保存的响应、HTTP 状态、收到响应的时间及查询耗时。页面每 5 秒读取平台记录，供应商查询由后台按既有间隔执行。
5. 完成后查看实际用量、归档视频及采购费用。费用仍受原有费用查看权限限制；未结算显示等待，不显示虚假的零费用。
6. 刷新详情或重新打开页面，原测试编号和生成次数不应变化。旧记录未保存的 HTTP 状态或查询过程会标明未记录，不补造历史数据。
