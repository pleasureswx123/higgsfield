# 模型供应商接入契约与差异清单

更新：2026-11-03。以用户提供的 VideoPlus 文档和当前适配器为依据。真实能力仍须对相应配置测试；不通过网页复制供应商 Key。

| 阶段 | 接口 | 输入和输出关键约束 |
|---|---|---|
| 图片/视频创建 | POST /v1/chat/completions | model、messages；其他参数顶层；Bearer鉴权、X-Biz-Id=op |
| 图片结果 | 同步 chat 响应 | choices[0].message.content 为 JSON 字符串；images[].b64_json 与内层usage |
| 视频创建结果 | 同步 chat 响应 | 解析 content 内层id作为供应商视频任务号 |
| 视频轮询 | GET /v1/video/tasks/{id} | running/终态；成功含content.video_url及最终usage |
| 临时上传 | POST /v1/assets/upload | multipart file，服务端构造boundary；返回临时url，通常24小时 |
| 素材注册 | POST /v1/mm/assets | URL、AssetType、Name、ProjectName（eva/nova）；返回Id |
| 素材状态 | POST /v1/mm/assets/get | Id；Active/Processing/Failed及临时签名URL |

普通参考可用上传后的URL；SD虚拟人物参考等待注册Active后使用asset://Id，不以查询得到URL替代。平台素材、元素、供应商素材ID不混淆。

图片参考后端Base64直传原文件，不自动压缩缩放。图片返回仅URL的兼容尚未实现。视频结果下载后校验和持久归档；临时URL不作为长期文件。

供应商上传文档支持图片20MB、视频500MB；平台还需满足当前配置的类型与容量限制。该上传接口文档未列音频上传能力，不能擅自推断支持。

## 差异与待确认

- Fast1080p、SD2.0 4K价格表与能力说明存在差异：价格配置不能开放未确认能力。
- H3与SD计价和参考规则独立，不假定H3虚拟人物注册与SD一致。
- 图片URL-only响应、制作端音频上传不作为已完成能力。
- 素材临时URL过期与文件是否自动删除是不同事实，未取得删除保证。
- 提交结果不明保留证据，不自动重发；下载归档失败只重试下载。

完整时序、源码落点见[技术方案](技术架构方案.md)第7～8节。
