# 视频模型配置与手动测试

更新：2026-11-03。使用已有供应商连接与密钥，保留图片配置。

1. 平台管理员进入“供应商与模型”，新增mm-eva-sd-2.5等已适配模型，不重新登记供应商。
2. 配置模型能力、各分辨率的有/无视频输入价格及汇率，保存。价格变更不要求重复测试。
3. 打开测试抽屉，查看Request与参数；点击暂不测试不调用供应商。
4. 点击抽屉内开始测试才实际生成视频并产生费用；跟随加载状态查看创建响应和最终轮询响应。
5. 测试通过并完成归档后按需启用到全平台；列表测试记录可看历史。
6. 制作端进入目标项目文件夹，选视频模型、720p、5秒、16:9及提示词，点击生成。最终视频应保存并显示到提交时目录。
7. 普通图使用参考图；SD虚拟人物在引用设置选择人物角色，后台上传→注册→查询Active→asset://Id。eva/nova隔离；参考视频按实际视频输入计价。
8. 费用管理员核对轮询成功结果的completion_tokens；不能使用创建响应的零Token。归档失败只重试保存，不重生成。

Fast1080p和SD2.0 4K不能仅凭报价启用。H3使用独立时长/图片计价与参数策略；制作端音频上传不作为已交付功能。详细验收见[人工验收](人工验收操作手册.md)。
