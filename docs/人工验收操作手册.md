# 人工验收操作手册

更新：2026-11-03。真实生成会产生供应商费用，由测试人员手动点击。配置和查看历史不应产生生成调用。

## 1. 管理端

1. 使用具备平台权限的账号登录，打开“供应商与模型”。已有连接和模型应保留。
2. 查看模型价格和汇率；仅在测试配置时修改并保存，验证不触发测试，历史任务价格不变。
3. 从模型列表打开测试记录，应看到历史Request/Response及状态。
4. 需要新测试时进入配置的测试步骤，点击测试入口：先打开抽屉，尚未提交。
5. 检查请求；点击“暂不测试”后应无新任务。再次打开，在抽屉点击“开始测试”才发起一次真实生成。
6. 等待loading与结果自动更新；刷新详情不重复调用。通过后按需启用，检查模型状态。

## 2. 图片生成

1. 制作端进入有权限的测试项目和目标文件夹。
2. 选择图片、mm-imagen2、1:1、2K、数量1，输入简单提示词。
3. 点击生成，观察提交锁和进行中状态；不要为了检查防抖故意大量发起独立任务。
4. 等待原目录显示生成素材，刷新后仍存在；生成记录能关联输入、模型和输出。
5. 查看者能查看下载，不能生成；制作人不能修改超出本人范围的内容。

## 3. 视频生成与元素

1. 切换视频、mm-eva-sd-2.5，选择模型支持的720p、5秒、16:9，先做无参考短视频。
2. 等待生成与归档完成，确认视频自动出现在提交目录并可播放下载。
3. 再按测试计划验证普通参考图片、参考视频、SD虚拟人物。人物参考须后台注册Active后使用asset://ID。
4. 选素材创建元素，再引用元素中的具体参考版本；修改元素后历史任务输入不变。
5. 归档异常只恢复下载保存，不重新生成。旧未关联视频不会自动回填。

## 4. 费用核对

1. 费用账号打开“用量与费用”；管理员测试选非项目消耗，制作生成选项目任务。
2. 打开明细，检查发起人、任务、模型、用量、币种和价格依据。
3. SD用量核对最终轮询completion_tokens；图片用量核对内层usage。
4. 项目与采购分别核对，不相加。待核算不当零元；历史金额调整留痕。
5. 对账导入与差异处理使用真实允许的供应商账单样本单独验收。

## 5. 上线前

验证NAS挂载失效、备份恢复、越权访问、后台恢复及两种主题。上述故障测试应在隔离测试环境执行，不破坏实际项目或账本。
