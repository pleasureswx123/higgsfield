# 生成任务调用记录

## 查询入口

管理平台 → 平台管理 → 运行记录 → 调用记录（`/studio/calls`）。

1. 输入任务 ID 后查询，或点击列表的「同任务记录」。此操作清除其他筛选，按新到旧列出该任务的调用，支持翻页。
2. 点击「查看详情」，打开只读抽屉。
3. 查看任务概况与创作输入、Request、cURL、Response；同一素材调用中的上传、注册、状态查询按时间分别展示。
4. 刷新详情只读取平台记录，不提交供应商请求。查看范围沿用 `operations:read` 与后台数据权限。

模型接入测试沿用「供应商与模型」中的测试详情；调用列表中的模型测试行会提示此入口。

## 记录语义

- 图片生成、视频提交、视频轮询，以及视频参考素材上传、注册和查询，在外部发送前保存脱敏请求快照；收到返回后保存脱敏返回及 HTTP 状态、传输状态、解析提示。
- 请求快照保存失败时不发送；查看时不读取当前模型配置重建历史请求。
- 已保存发送意图但没有返回证据，不表示供应商未执行；网络异常、超时不能作为免费或可重复生成的依据。
- JSON 响应展示结构化内容；非 JSON 返回展示有界脱敏文本及解析错误。超限或编码错误可能只有 HTTP 状态和错误提示。
- 密钥、认证信息、临时媒体地址与费用敏感字段脱敏；媒体 Base64、深层或超长内容会省略并提示。记录不是原始网络包的逐字节副本。
- cURL 为 Bash 格式，认证与媒体地址是占位符。复制不发送请求，手动执行属于新请求。流式文件上传不提供伪造的可执行 cURL。
- 历史调用没有此快照时明确提示缺失，不补造正文。新增记录使用已有 JSONB 字段，本次无需业务数据库迁移。
- 收到响应头后发生网络异常或超时，仍保留已观察到的 HTTP 状态码；诊断记录失败阶段、异常类型与原因类型链、已接收字节数，不保存可能包含密钥的原始异常文本。HTTP 200 不代表图片结果接收完整。
- 同步图片提交结果未知时，工作器检查已保存的完整响应证据；没有可恢复证据或证据不能解析为有效结果时，清空下次调度时间，停止自动恢复并要求人工核查。任务及费用仍保留未知事实，不自动重发生成。旧调用未记录的异常类型不能追溯补造。

## 生效与验收边界

后端及图片、视频工作进程加载新代码后，新调用才开始保存上述快照。保留现有原始响应加密证据机制。本功能没有代替用户发起真实付费生成。

自动验证覆盖请求先保存后发送、失败时禁止发送、请求与实际 HTTP 正文对应、返回持久化、脱敏、超时、权限范围与前端请求取消。实际页面验收和真实供应商端到端生成须分别记录，不能以源码或隔离测试替代。

### 同步图片调用的有界等待

同步图片生成工作器使用独立传输时限：整个 HTTP 请求（生成等待及响应正文下载）最多 900 秒，并受连接配置的任务总时限约束；连续读取无数据最多 300 秒，连接建立时限沿用原配置。其他调用继续使用原操作时限。此策略不修改历史连接版本。

图片工作器处理时限至少 1200 秒，为请求后解析和落盘留出余量；执行期间仍按已有心跳续租。超时记录保留已收到的 HTTP 状态、字节数、异常类别和实际使用的时限，不自动重新发送图片请求。已有结果未知任务不会因该策略变更恢复提交。
