# 供应商模型目录与制作端选择规则

更新：2026-11-03。平台当前以 VideoPlus MM 接入协议为基础，模型是否对用户可见取决于实际已配置、已启用能力，不把目录列出等同于已付费测试。

| 模型名 | 类型与差异 |
|---|---|
| mm-imagen2 | 图片生成/编辑，网关别名，底层 gpt-image-2 |
| mm-eva-sd-2.0 / mm-nova-sd-2.0 | SD 2.0 标准版，国际/国内素材域 |
| mm-eva-sd-2.0-fast / mm-nova-sd-2.0-fast | SD 2.0 Fast |
| mm-eva-sd-2.5 / mm-nova-sd-2.5 | SD 2.5 标准版 |
| mm-eva-sd-2.5-fast / mm-nova-sd-2.5-fast | SD 2.5 Fast |
| mm-h3 | H3 视频，参数和计价独立适配 |

制作端图片优先默认 mm-imagen2，视频优先默认 mm-eva-sd-2.5；前提是接口返回可用，保留已有有效草稿或手动选择，不能绕过停用状态。图片默认1:1；参数展示按模型能力裁剪。

SD 标准版当前常用480p/720p/1080p；Fast不因报价表列1080p而自动开放；SD2.0的4K同理。H3不得照搬SD人物注册策略。音频上传并未因供应商支持audio_url就成为制作端已交付能力。

模型列表不向制作用户堆叠采购单价或底层规格ID；管理员在供应商与模型页配置，费用管理员在费用页面核查。
