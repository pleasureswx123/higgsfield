1 核对范围与结论

以最新 AGENTS.md 和用户已确认约束为最高工程基线，本轮对 docs 原有15份 Markdown及其HTML配对进行清单、跨文档关键规则、接口摘要、状态、优先级、版本和链接核对；新增本文后为16份配对文档。价格来源目录的4张截图作为原始来源附件保留，不修改或以其推断当前官网价格。

已修正文中发现的冲突，不以本报告附注代替源文档修订。数据库仍为 PostgreSQL，前后端仍严格遵循若依及 Vue3 约定；内网部署和 NAS 长期媒体存储为已确认事实。没有新增业务范围、批准默认角色或预算提案，也没有替用户确定服务器配置。

当前文档具备推进无依赖工程准备的基础，但不能据此认定所有业务模块可直接编码或正式消费。§5 将待确认事项分为模块编码前、真实联调/消费前、正式部署前，不要求所有运维参数先确定才开展基础工作。

6 本轮检查方法与限制

检查对象为全部Markdown内容的跨文档关键约束、规则登记及引用；HTML从对应Markdown统一生成。静态核对包括版本索引、源规则69条不重标级、API-DB九项登记、链接目标、配对文件和Mermaid图表渲染。保留历史修订记录中的旧版本号，不将其误当当前版本。

本报告不声称证明所有未来DTO/DDL或运行行为一致：80张表仍需真实迁移与事务测试，供应商样例仍需逐能力实测，权限缓存/页面/上线步骤仍需实现和运行验收。未进行数据库连接、收费调用、服务器部署、NAS挂载或业务测试；未修改业务代码。

后续确认应记录决定、确认人、日期、关联D/规则ID、受影响页面/API/表/用例，先更新源文档再同步索引与HTML。无需创建与源规则冲突的新优先级列表。

由同目录 文档全量核对与编码前确认清单.md 生成，内嵌 0 张 SVG 图；修改以 Markdown 为准。
