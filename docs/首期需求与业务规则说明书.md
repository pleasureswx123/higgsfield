# 首期需求与业务规则说明书

更新：2026-11-03。当前完整需求统一维护在[完整 PRD](AI图片与视频制作平台PRD-全流程版.md)，本文件保留关键规则索引，避免重复正文出现分歧。

| 规则组 | 当前约束 |
|---|---|
| 角色 | 系统角色与项目角色分离；Owner≥负责人≥制作人≥查看者 |
| 接入 | 同一供应商多模型共享连接凭据，模型独立配置和启停 |
| 模型范围 | 启用后全平台现有/新项目可用，保留项目权限 |
| 生成 | 组件编辑草稿，一键受理，防重复；提交后不取消 |
| 参考 | 素材可直接参考，元素是可选复用组织；SD 人物使用供应商 asset ID |
| 归档 | 图片与视频原文件长期保存；提交时文件夹关联；归档失败单独重试 |
| 费用 | 实际用量、USD、项目采购同价分别记账；无预算预占 |
| 历史 | 输入与价格快照固定；调整不覆盖历史原账 |
| 交互 | 测试先开抽屉看请求再决定；完成自动显示；普通管理员不用命令 |
| 暂缓 | 公共素材库、剪辑、文本聊天、工具市场、训练 |

业务验收编号为 PRD-01～PRD-12，见完整 PRD 第14节。历史规则编号只用于追溯旧设计，不作为新开发优先级或当前验收状态。
