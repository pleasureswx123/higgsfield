# 管理端导航与工作台手动验收

更新：2026-11-03。

1. 费用管理员登录：工作台只出现费用相关职责；用量明细可用，不能进入无权的供应商写入操作。
2. 平台管理员登录：供应商与模型、调用和异常等授权入口可见；无用户/部门权限时不显示对应入口。
3. 综合管理员登录：平台、费用、用户与部门管理按已授予权限同时可用；不因此自动取得所有项目内容编辑权。
4. 模型列表可配置、查看测试记录和执行授权启停；新管理员不必理解内部价格簿或规格ID。
5. 测试入口先开抽屉，看Request后决定开始；暂不测试不调用；运行中有加载状态，结果自动展示。
6. 验证亮暗主题、折叠侧栏、窄窗口、空数据与权限错误；不能把读取失败标为未配置。
