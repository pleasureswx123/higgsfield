# 管理端导航与工作台手动验收

日期：2026-11-02。日常入口按业务操作组织，技术配置按需展开。此次不修改数据库记录、角色权限或供应商配置，不调用供应商测试。

## 日常入口

- 供应商与模型：供应商设置、添加模型、确认价格、测试和启用。
- 用量与费用：根据现有权限查看消耗与统计。
- 运行记录：调用记录和异常任务。

侧栏不再显示“高级设置”、密钥、模型版本、价格来源、项目专用配置等内部入口。原路由仍保留并继续执行原权限校验；隐藏菜单不等于撤销或增加权限。

供应商密钥和连接参数在“供应商设置 → 维护详情”中查看。模型历史版本、价格维护和能力设置在该模型的“更多操作 → 维护详情”中查看。原项目专用配置保留，日常模型启用无需逐项目配置。旧 `mode=advanced` 链接打开简化供应商表单；维护连接参数使用明确的 `mode=connection-details` 入口。

## 手动检查

1. 刷新管理端，必要时退出重登以重新加载菜单。侧栏只呈现当前账号有权限的日常入口，没有“高级设置”。
2. 当前旧高级页面刷新后应显示简化供应商设置，首屏不出现适配器、域名白名单或超时参数。
3. 返回模型列表：未配置供应商时提示先配置；存在待完成模型时显示“继续配置”按钮；已有启用模型时提示可到制作端使用。
4. 点击“供应商设置”，密钥在同一流程选择或填写；仅在主动展开维护详情后才显示连接维护和密钥轮换入口。
5. 点击模型的“配置模型”确认价格和启用状态。无需为了验证页面再次发起付费测试。
6. 点击“更多操作”，维护内容默认折叠。展开后仍可查看原历史记录，权限不足的按钮不显示。
7. 工作台不再出现项目专用配置卡片或要求逐项目开放的提示。
8. 切换亮暗主题，检查卡片、菜单、表单、弹窗可读，输入与筛选保留。
9. 费用管理员只看到获授权的入口，不因菜单简化而获得供应商操作权限。

自动检查覆盖菜单隐藏与原路由保留、权限边界、只读加载和接入编排；浏览器视觉与真实用户操作由手动验收确认。
