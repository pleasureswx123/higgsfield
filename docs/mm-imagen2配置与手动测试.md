# mm-imagen2 配置与手动测试

更新：2026-11-03。已有配置全部复用，不为了看页面重复付费测试。

1. 平台管理员进入“供应商与模型”。首次配置供应商地址和密钥；已有VideoPlus连接时直接复用。
2. “新增模型”选择mm-imagen2，保存。保存模型不调用供应商。
3. 配置模型，核对图片能力、输入/输出单价（初始5/30 USD每百万Token）与价格依据，保存继续。
4. 测试入口打开抽屉，先查看待发送请求和脱敏cURL；可选择暂不测试。
5. 在抽屉内点击“开始测试”才生成一张图片并产生真实费用，等待进度与Response自动更新。
6. 测试通过后按需启用到全平台；现有和新项目自动可用。模型列表“测试记录”可查历史，无需重复测试。
7. 已启用后修改价格不会自动重测，历史任务仍使用原价格。
8. 制作端项目内选择图片mm-imagen2、1:1、2K、1张，输入提示词生成；检查原文件夹素材、生成记录和费用。

图片使用网关chat/completions接口与Base64输出；仅URL返回未支持。参考图片后端原文件Base64直传，不自动压缩缩放。详细验收见[人工验收](人工验收操作手册.md)。
